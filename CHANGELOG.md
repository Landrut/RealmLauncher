# Что нового

## v1.2.0.0

### Полностью новый внешний вид

Лаунчер переоформлен с нуля — стал современнее, аккуратнее и понятнее.
Состояние сервера, количество игроков, вход и журнал запуска теперь разнесены
по отдельным блокам, а не свалены в одну строку внизу.

### Три темы на выбор

Бронзовая, синяя и аметистовая. Переключаются мгновенно в настройках,
перезапуск не нужен.

### Настройки стало удобнее

Всё разложено по разделам, переключатели вместо галочек, а изменения
сохраняются сразу — больше ничего не теряется при закрытии.

### Работает быстрее

Лаунчер быстрее запускается и меньше нагружает систему.

### Исправлено

- Окно больше не подвисает при проверке сервера
- Список выбора темы больше не вылезает за пределы окна
- Добавлена кнопка сворачивания окна
- Лаунчер больше не закрывается с ошибкой при повреждённых настройках
- Мелкие визуальные недочёты
